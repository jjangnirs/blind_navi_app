# ADR 0021: 차량용 신호등 고공 분리 배제 및 한손 파지 손떨림 적응형 녹색 판정 안정화

## 1. 배경 및 문제 상황
야외 실제 횡단보도 보행 시험(15시경) 및 비행 로그 분석 결과, 사용자가 실제 녹색 보행 신호등을 바라보고 있음에도 음성으로 녹색 신호가 안내되지 못하는 현상이 발생하였다. 원인 분석 결과 다음의 물리적·환경적 요인이 결합된 것으로 확인되었다.

1. **상단 차량용 신호등(Vehicle Traffic Light)의 적색 간섭 및 오판**:
   - 보행 신호가 녹색일 때 교차로 상단에는 차량용 신호등의 적색 램프가 차도 중앙(X ≈ 0.50) 상공에 켜져 있는 경우가 많다.
   - 단일 원형 램프만 발광할 경우 종횡비(Aspect Ratio 1.0)만으로는 가로형 차량 신호등으로 걸러지지 않았으며, 차도 중앙에 위치하여 화면 중심축과의 거리가 보행등보다 가깝게 계산되어 `primaryRed`로 잘못 선택되었다.
   - Zero False-Green 원칙에 따른 경합 시 적색 우선(Red Precedence) 정책으로 인해, 실제 50개 이상의 화소로 선명하게 켜진 보행등 녹색이 존재함에도 상단 차량 적색에 의해 전체 판정이 `RED`로 강제되었다.

2. **한손 파지(One-Handed Holding) 시 손떨림 및 연속 프레임 리셋**:
   - 시각장애인이 한 손에는 지팡이, 한 손에는 스마트폰을 들고 대기할 때 초당 수 회의 손떨림(Jitter)이 발생하여 화면 내 신호등 중심 좌표가 10~15% 흔들린다.
   - 기존 검증기(`LocalVlmSignalVerifier`)의 중심 거리 허용 한계(8%)를 초과하여 매 2~3프레임마다 Track ID가 `track-dyn-1` -> `track-dyn-2`로 재생성되었다.
   - 결정 엔진(`CrossingDecisionEngine`)이 Track ID 변경 시 `DIFFERENT_TRACK_TRANSITION_REJECTED`를 발동하여 누적 녹색 카운트를 0으로 초기화하고 슬라이딩 윈도우를 비움으로써, 5~8회의 연속 녹색 합의에 도달하지 못하고 음성이 침묵하였다.

## 2. 의사결정 및 기술적 해결책

### 1) 상단 차량용 신호기 수직 고도(Elevation) 분리 및 에너지 압도도 필터
- **수직 대역 분리**: 차도 상공 가공 설치되는 차량 신호기($Y_{norm} < 0.22$)와 보도 기둥 눈높이에 위치하는 보행 신호기($Y_{norm} \in [0.22, 0.70]$)의 고도를 분리.
- 상단 차도 영역의 적색 광원은 보행 영역의 녹색 신호등과 경합 시 보행 신호 판정을 기각하지 못하도록 배제.
- **발광 면적(에너지) 압도도**: 보행 녹색 화소수가 미세 반사광/상단 적색의 2배 이상(`primaryGreen.pixelCount >= primaryRed.pixelCount * 2.0f`)일 경우 능동 점등된 보행 신호를 확실하게 선택.

### 2) 한손 파지 손떨림 적응형 공간 추적 및 연속성 승계
- **중심 거리 허용 완화**: `LocalVlmSignalVerifier`의 손떨림 중심 거리 허용 범위를 0.08에서 0.18(화면 18%)로 확장하고, 중앙 뷰파인더 관심 영역($cx \in 0.15..0.85, cy \in 0.10..0.75$) 내에서는 최대 0.25까지 동일 Track으로 유지.
- **동적 움직임 기각 완화**: 손떨림 진동($dist \le 0.18f$)은 고속 주행 차량 기각 대상에서 안전하게 제외.
- **Track ID 승계(Inheritance)**: `CrossingDecisionEngine`에서 동일 시퀀스 내 `track-dyn-*` 간의 연속 전이는 손떨림으로 인한 ID 증가로 인식하여 슬라이딩 윈도우와 녹색 누적 카운트를 보존.
- **단일 블러 프레임 완충**: 한손 파지 시 순간적인 프레임 블러로 1프레임 `UNKNOWN`이 발생하더라도 즉시 카운트를 0으로 리셋하지 않고 점진적으로 감쇄하여, 5프레임 중 75% 이상 녹색 합의 시 `GREEN_ESTIMATE` 정상 승인.

### 3) 뷰파인더 및 조준선 디바운싱 강화
- `CrossingAssistViewModel`의 조준선 이탈 디바운싱을 3프레임(100ms)에서 8프레임(270ms)으로 확장하여 손떨림 중 조준 풀림 방지.
- 조준 음성 발화 쿨다운(4초)을 적용하여 신호 대기 중 조준 반복 발화가 녹색 신호 음성 안내를 간섭하지 않도록 보장.

## 3. 검증 결과
- `CameraVisionSignalEstimatorTest.testOverheadVehicleRedLightDoesNotVetoPedestrianGreenLight`: 상단 차도 적색 신호가 존재해도 보행 녹색 신호 정상 인식 확인.
- `CrossingDecisionEngineTest.testHandheldDynamicTrackJitterAccumulatesGreen`: 한손 파지 손떨림으로 인한 Track ID 연속 전이 상황에서도 5프레임 누적으로 `GREEN_ESTIMATE` 정상 발화 확인.
- 전체 174개 안드로이드 단위 테스트 100% 통과.
