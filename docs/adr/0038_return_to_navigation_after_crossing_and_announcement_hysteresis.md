# ADR-0038: 횡단 완료 후 길안내 자동 복귀, 화면 이중 닫힘 수정 및 적색/확인불가 안내 반복 억제

## 1. 배경 및 문제 의식 (Context)
2026-10-02 18:28~18:33 현장 테스트(v38) 로그:
1. **횡단 후 경로 초기화**: 카메라 화면 종료 시 `FinishScreen` 효과가 종료 애니메이션 중 한 번 더 실행되어 **길안내 화면까지 닫혔다**. 경로 요약 화면이 출발 위치에서 30 m 이상 이동했음을 감지해 경로를 조용히 재검색(546 m → 430 m)했고, 사용자가 다시 시작해 안내가 처음부터 재개됐다(18:30:21).
2. **재진입 시 경로 재설정**: 길안내 화면이 다시 그려질 때마다 `LaunchedEffect(route)`가 `setRoute()`를 호출해 진행 상태·재탐색 경로·자동 전환 이력이 초기화됐다(`ROUTE_START` 중복 기록의 원인).
3. **안내 반복**: 자동 전환 후에도 휴대폰을 바닥 쪽으로 든 상태(pitch −75~−84°)라 프레임 절반이 각도 불량 → 확정 상태가 적색↔확인불가로 20초에 7회 바뀌며 매번 음성 안내.
4. 횡단 후에는 사용자가 직접 종료 버튼을 눌러야 지도로 돌아갔다.

## 2. 결정 사항 (Decisions)

### 2.1 횡단 완료 후 자동 복귀
- 카메라 화면이 열릴 때 건너려는 횡단보도(경로상 시작·건너편 끝 위치)를 감시 등록 (`onCrossingAssistOpened`).
- 건너편 끝 = 다음 분기점 위치(비정상이면 시작 + 20 m).
- 완료 조건: 건너편 끝 3 m 전 도달 GPS 2회 연속, 정확도 ≤ 25 m, 경로 위, (녹색 확정 또는 보행 중 ≥ 0.6 m/s).
  - ADR-0039에서 최소 경과 시간 조건 추가.
- 완료 시 카메라 화면 쪽에서 "횡단보도를 건넜습니다. 길안내로 돌아갑니다." 음성 후 지도 화면으로 복귀 (카메라 화면이 떠 있는 동안에는 길안내 화면의 효과가 수집되지 않으므로 별도 `crossingCompleted` 흐름 사용).
- 5분 내 미완료 시 감시 종료, 수동 종료 시 감시 해제. `[CROSSING_RETURN]` 비행 기록.

### 2.2 화면 이중 닫힘·재진입 초기화 수정
- 종료/자동 복귀는 현재 화면이 카메라 화면일 때만 뒤로 이동.
- `ensureRoute()`: 같은 원본 경로로 안내 중이면 재설정하지 않음.

### 2.3 안내 반복 억제 (시간 기반 히스테리시스)
- 확정된 적색/녹색 → 확인불가 전환: 6프레임 이상 **그리고 4초 이상** 연속일 때만 (녹색 확정은 5프레임 그대로).
- 적색 재안내 8초 쿨다운. 단, 그 사이 확인불가를 안내했다면 즉시 적색 재안내.
- 확인불가 안내 10초 쿨다운.
- `[FRAME]` 기록에 휴대폰 기울기(`Pitch=`) 추가.
