# ADR-0033: C-ITS 실시간 신호 연동, 아이나비식 상태 전이 트리거 및 지도 시각화

## 1. 배경 및 문제 의식 (Context)
2026년 9월 27일 횡단보도 현장 비전 테스트 결과, 온디바이스 카메라 단독 픽셀/색상 판정 방식은 다음 3대 본질적 한계에 직면함:
1. **간판/버스 오인 vs 신호등 기각의 상충 (풍선 효과)**: 간판을 막기 위해 하우징/광도 조건을 조이면 역광·그늘에서 실제 신호등이 기각되고, 풀면 간판을 녹색불로 오인.
2. **시각장애인 파지 및 흔들림**: 대기 중 및 횡단 중 팔이 아래로 처지거나 보행 진동이 발생하여 0.3초 핑퐁(화면-음성 불일치) 발생.
3. **사용자의 요구**:
   - "아이나비 차량용 신호등 인식처럼 적용할 수 없는가?"
   - "공공 C-ITS 실시간 신호 데이터를 연동하고, C-ITS 신호등이 있는 건널목을 지도에 표기해 달라."

## 2. 결정 사항 (Decisions)

### 2.1 C-ITS 실시간 신호 데이터 연동 (`CitsRealSignalStatusProvider`)
- 사용자 제공 인증키(`ca0040c954...`)를 기반으로 대한민국 경찰청 및 광주광역시 C-ITS / UTIC 실시간 보행 신호(SPaT) Open API 연동.
- HTTP 통신으로 교차로별 현재 신호 상태(`RED` / `GREEN`) 및 잔여 시간(`remainingSeconds`)을 실시간 수신.
- 서킷 브레이커(`SignalCircuitBreaker`) 및 킬스위치 보호로 네트워크 장애 시 안전 실패(Fail-safe) 보장.

### 2.2 아이나비 차량용 ADAS(TLCA) 패러다임 완벽 이식
1. **적색 앵커(Red Anchor) 락온**:
   - 허공에서 초록불을 탐색하지 않고, 대기 중 정면에 위치한 세로 2구 보행등의 빨간불 2D 좌표를 앵커로 고정.
   - 초록색 간판이나 지나가는 초록 버스는 "이전에 빨간불이었던 적이 없는 물체"이므로 애초에 100% 무시.
2. **상태 전이(Transition) 감지**:
   - 상단 빨간불이 꺼지고 바로 아래 초록불이 켜지는 동시 전이 이벤트만 감시.
3. **1회성 출발 알림(1-Shot Departure Trigger) & 비전 즉시 동결(Freeze)**:
   - 녹색 신호 확인 순간 1회 발화: *"신호가 바뀌었습니다. 건너가세요. (잔여시간 25초) 좌우를 살피며 횡단하세요."* + 강력 햅틱 1회.
   - **출발 알림 즉시 비전 분석을 자동 종료(Freeze)**하여 건너는 도중 폰 흔들림으로 인한 핑퐁/재판정 영구 박멸.

### 2.3 지도 내 C-ITS 건널목 시각화 (`RealRouteMapView.kt`)
- **C-ITS 실시간 신호 연동 건널목 (🚦)**:
  - 에메랄드/시안 블루 네온 그라디언트 + 실시간 펄스 링 애니메이션(`cits-pulse-ring`) + `[C-ITS]` 뱃지.
  - 마커 팝업: *"🚦 C-ITS 실시간 신호 연동 건널목 (잔여시간 실시간 음성 안내)"*
- **일반 건널목 (🚶)**:
  - 주황색 원형 핀 + 보행자 아이콘.
  - 마커 팝업: *"🚶 일반 횡단보도 (카메라 비전 보조 사용)"*
- **지도 좌측 상단 플로팅 범례(Legend)**:
  - `[● C-ITS 신호 연동 / ● 일반 횡단보도]` 범례 패널 상시 표출.
