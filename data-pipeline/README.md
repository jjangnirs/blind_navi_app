# Safe Cross KR Data Pipeline

공공데이터(전국신호등표준데이터, 전국횡단보도표준데이터 등)의 수집, 불변 원시 저장, 엄격한 정규화, 품질 검사 및 안전 배포를 담당하는 데이터 파이프라인 패키지입니다.

## 핵심 데이터 처리 원칙

1. **정적 시설 속성과 실시간 신호의 엄격 분리**:
   - 공공데이터의 신호등·횡단보도 정보는 시설 위치, 음향신호기 유무, 점자블록 유무 등 **정적 시설 속성**입니다.
   - 이를 현재 시점의 실시간 적색/녹색 신호로 절대 해석하거나 변환하지 않습니다.
2. **엄격한 삼항 논리 (Ternary Logic)**:
   - 음향신호기, 점자블록 등의 시설 여부는 반드시 `YES`, `NO`, `UNKNOWN`(정보 없음)의 3가지 상태로 관리하며 공란이나 불명확한 값을 임의로 가정하지 않습니다.
3. **불변 원시 데이터(Raw) 및 출처 추적**:
   - 수집된 원시 CSV는 SHA-256 해시와 함께 원본 그대로 보존되며, 가공 파이프라인(staging $\to$ canonical $\to$ published)의 모든 레코드에는 원천 출처, 기준일자, 변환 타임스탬프가 유지됩니다.
4. **현장 검증된 Allowlist 기반 발행**:
   - 신호등↔횡단보도 공간조인 후보(10m/20m/30m) 중 현장 실사가 완료되고 횡단 방향과 신호 연결이 1:1 확정된 레코드만 published 상태로 서비스에 노출합니다.

## 파이프라인 구조

- `loaders/`: 공공데이터 포털 원시 파일 다운로드 및 무결성 해시 기록
- `parsers/`: 대한민국 좌표계(WGS84) 범위 검증, Y/N/null 정규화 파서
- `spatial/`: PostGIS 기반 횡단보도 회랑(Corridor) 및 신호등 매핑
- `quality/`: 결측치, 좌표 이탈, 명칭 모호성 격리 및 품질 검사기
- `publish/`: 최종 검증된 GeoJSON/PostgreSQL 테이블 발행기
